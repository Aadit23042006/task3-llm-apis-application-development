🚀 **Project Update: AI Chat Lab — LLM APIs & Application Development**

I recently completed a hands-on project focused on integrating Large Language Model (LLM) APIs into an interactive application.

For this project, I developed **AI Chat Lab**, a Python and Streamlit-based conversational AI application that demonstrates API-powered chat and key application development concepts.

✨ **Key Features**
• LLM API integration using an OpenAI-compatible client  
• Interactive Streamlit chat interface with conversation history  
• Custom system instructions and model parameters  
• Structured JSON response mode (where supported)  
• Demo Mode for testing without API credentials  
• Error handling and retry mechanisms  
• Token usage reporting and approximate cost estimation  
• Google Colab notebook with API experiments and regression checks
